다음 콘텐츠의 가능성을
공개 데이터에서 발견합니다.

ARNDI Research Radar는 주식회사 브레인스토밍이 운영하는 내부 콘텐츠 조사 도구입니다. 공개된 동영상과 채널 데이터를 검토하여 최근 관심이 움직이는 주제와 채널별 상대 성과를 파악합니다.

작동 방식 보기데이터 처리 원칙
공개 동영상·채널 데이터 출처

HOW IT WORKS

발견부터 검토까지, 세 단계로 작동합니다.

01

공개 영상 발견

사전에 정의한 연구·대학원·R&D 관련 검색어로 공개 동영상을 찾고 제목, 게시일과 채널 정보를 정리합니다.

02

성과 맥락 비교

현재 공개 조회수와 시간에 따른 변화량을 확인하고, 같은 채널·같은 형식의 최근 영상과 비교합니다.

03

사람이 최종 판단

분석 결과는 아이디어 참고 자료일 뿐입니다. 주제 선정과 콘텐츠 제작 여부는 담당자가 직접 검토하고 결정합니다.

DATA & METRICS

원본 통계와 자체 계산값을 분리합니다.

화면에서는 YouTube Data API가 제공하는 공개 값과 ARNDI가 독립적으로 계산한 값을 명확하게 구분합니다.

YouTube 공개 데이터제목, 게시일, 채널명, 동영상 길이, 공개 조회수·좋아요 수·댓글 수
최근 조회 증가 속도두 관측 시점 사이의 공개 조회수 증가량을 실제 경과시간으로 나눈 ARNDI 자체 계산값
채널 기준 성과 배수현재 공개 조회수를 같은 채널·같은 형식의 최근 유효 영상 조회수 중앙값과 비교한 ARNDI 자체 계산값

중요: 자체 계산 지표는 YouTube가 제공하거나 보증하는 측정항목이 아니며, 공개 데이터를 바탕으로 주식회사 브레인스토밍이 독립적으로 산출합니다.

BOUNDARIES

내부 조사에 필요한 범위만 사용합니다.

  • 일반 사용자에게 판매하거나 구독 서비스로 제공하지 않습니다.
  • 동영상을 자동 업로드·수정·삭제하지 않습니다.
  • Google 계정 로그인이나 OAuth 권한을 요구하지 않습니다.
  • 비공개 YouTube Analytics 데이터에 접근하지 않습니다.
  • 시청자 개인을 식별하거나 민감정보를 추론하지 않습니다.
  • 모든 후보 영상은 원본 YouTube 페이지로 연결됩니다.

동영상과 채널 정보의 출처는 YouTube입니다. 아래 공식 브랜딩은 데이터 출처를 표시하며, 누르면 운영 채널의 YouTube 페이지로 이동합니다.
