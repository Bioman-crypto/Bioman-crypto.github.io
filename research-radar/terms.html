서비스 이용약관

ARNDI Research Radar · 시행일 2026년 10월 19일

1. 목적

본 약관은 주식회사 브레인스토밍(이하 “회사”)이 운영하는 내부 콘텐츠 조사 도구 ARNDI Research Radar(이하 “서비스”)의 이용 조건과 운영 원칙을 정합니다.

2. 서비스의 성격

서비스는 회사의 승인된 담당자가 공개 YouTube 동영상 및 채널 데이터를 검토하고 자체 교육 콘텐츠의 주제와 참고 형식을 연구하기 위해 사용하는 내부 도구입니다. 일반 대중을 대상으로 판매하거나 회원가입·구독 형태로 제공하지 않습니다.

3. 제공 기능

  • 사전 정의된 검색어를 사용한 공개 동영상 발견
  • 공개 동영상 및 채널 메타데이터와 통계의 정리
  • 관측 시점 간 공개 조회수 변화 계산
  • 같은 채널·같은 형식의 최근 영상과 상대 성과 비교
  • 콘텐츠 기획을 위한 내부 검토 자료 제공

4. YouTube API 사용과 출처 표시

서비스는 YouTube Data API를 사용합니다. YouTube가 제공하는 원본 통계와 회사가 독립적으로 계산한 파생지표는 화면에서 구분해 표시합니다. 자체 계산값은 YouTube가 제공·승인·보증하는 측정항목이 아닙니다. 원본 콘텐츠와 권리에 관한 사항은 해당 YouTube 페이지와 YouTube 약관을 따릅니다.

5. 금지되는 사용

  • API 데이터 또는 인증정보의 무단 판매, 재배포 또는 공개
  • 시청자 개인을 식별하거나 민감한 특성을 추론하는 행위
  • YouTube 데이터의 출처를 숨기거나 원본 통계를 왜곡하는 행위
  • 접근 제한, 할당량 또는 보안 통제를 우회하는 행위
  • YouTube 서비스 약관 또는 API 개발자 정책에 위반되는 사용

6. 계정과 접근

서비스는 공개 회원가입이나 데모 계정을 제공하지 않습니다. 승인된 내부 담당자만 로컬 운영 환경에 접근할 수 있으며, 공개 YouTube 데이터를 조회할 때 Google OAuth 로그인을 요구하지 않습니다.

7. 지식재산권

YouTube, 동영상, 썸네일 및 채널 데이터에 관한 권리는 각 권리자에게 있습니다. 회사는 API 약관이 허용하는 범위에서 이를 표시하고 분석합니다. 서비스의 코드, 화면 구성 및 독립적인 분석 로직에 관한 권리는 회사 또는 정당한 권리자에게 있습니다.

8. 서비스 변경 및 중단

회사는 정책 준수, 보안, 유지보수 또는 내부 운영상의 필요에 따라 서비스의 전부 또는 일부를 변경하거나 중단할 수 있습니다. YouTube API 정책 또는 제공 범위가 변경되면 서비스 기능도 이에 맞게 조정될 수 있습니다.

9. 정확성과 책임 제한

서비스의 분석 결과는 콘텐츠 기획을 위한 참고 자료이며 조회수, 사업 성과 또는 콘텐츠 성공을 보장하지 않습니다. API 데이터의 지연, 누락 또는 외부 서비스 변경으로 결과가 달라질 수 있습니다. 회사의 담당자는 분석 결과를 독립적으로 검토한 뒤 의사결정을 내려야 합니다.

10. 개인정보 및 데이터 처리

서비스의 데이터 처리 기준은 개인정보처리방침에 따릅니다.

11. 준거 정책

서비스 사용에는 본 약관과 함께 다음 정책이 적용됩니다.

  • YouTube 서비스 약관
  • YouTube API 서비스 약관
  • YouTube API 서비스 개발자 정책
