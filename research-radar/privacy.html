ARNDI Research Radar · 시행일 2026년 10월 19일

핵심 안내

ARNDI Research Radar는 공개된 YouTube 동영상 및 채널 데이터만 API Key 방식으로 조회합니다. 일반 사용자의 Google 로그인, OAuth 토큰, 시청 기록, 비공개 채널 분석 데이터 또는 민감한 개인정보를 수집하지 않습니다.

1. 운영 주체와 적용 범위

주식회사 브레인스토밍(이하 “회사”)은 내부 콘텐츠 조사 도구인 ARNDI Research Radar(이하 “서비스”)를 운영합니다. 본 방침은 서비스가 YouTube Data API를 통해 처리하는 데이터와 서비스 운영 과정에 적용됩니다.

2. 사용하는 API 서비스

서비스는 YouTube Data API를 사용하며, 공개 데이터 조회를 위해 search.list, videos.list, channels.list, playlistItems.list 엔드포인트를 사용합니다. 서비스는 Google 계정 로그인을 요구하지 않으며 OAuth 2.0 사용자 인증정보를 수집하거나 저장하지 않습니다.

3. 처리하는 데이터

3.1 YouTube가 공개적으로 제공하는 데이터

  • 동영상 ID, 제목, 설명, 썸네일, 게시일, 재생시간
  • 채널 ID와 채널명
  • 공개 조회수, 좋아요 수, 댓글 수 등 공개 통계
  • 검색어, 정렬 방식 및 데이터 관측 시각

3.2 독립적으로 계산하는 지표

  • 최근 조회 증가 속도: 두 관측 시점의 공개 조회수 차이를 실제 경과시간으로 나눈 값
  • 채널 기준 성과 배수: 현재 공개 조회수를 같은 채널·같은 형식의 최근 유효 영상 조회수 중앙값과 비교한 값

위 지표는 YouTube가 직접 제공하거나 보증하는 측정항목이 아닙니다. 회사가 공개 API 데이터를 바탕으로 독립적으로 계산합니다.

3.3 수집하지 않는 데이터

  • 시청자의 이름, 이메일, 계정 ID 또는 시청 기록
  • 비공개 YouTube Analytics 및 YouTube Reporting API 데이터
  • Google OAuth 액세스 토큰 또는 갱신 토큰
  • 건강, 정치성향 등 민감정보와 개인별 프로파일

4. 이용 목적

데이터는 공개 동영상의 최근 변화와 채널 내 상대 성과를 검토하고, ARNDI 교육 콘텐츠의 주제와 참고 형식을 결정하기 위한 내부 조사 목적으로만 사용됩니다. 서비스는 외부 사용자에게 판매·대여하거나 광고 타기팅에 사용하지 않습니다.

5. 보관, 갱신 및 삭제

  • 동영상 제목, 설명, 썸네일, 채널명 등 비통계 API 데이터는 30일 이내에 갱신하거나 삭제합니다. 현재 운영 기준은 29일 이내 갱신 또는 삭제입니다.
  • 공개 조회수·좋아요 수·댓글 수와 이를 이용한 파생지표는 YouTube의 파생 측정항목 및 데이터 보관 관련 추가 정책 적용 승인을 받은 범위에서 최대 36개월 동안 보관할 수 있습니다.
  • 추가 정책 승인을 받지 않았거나 승인이 종료된 경우에는 적용되는 YouTube API 개발자 정책에 따라 데이터를 갱신 또는 삭제합니다.
  • 운영 목적이 끝나거나 API 접근이 종료되면 관련 데이터를 안전하게 삭제합니다.

6. 제3자 제공과 판매

회사는 서비스가 수집한 API 데이터를 제3자에게 판매하지 않습니다. 또한 외부 광고, 사용자 신용평가 또는 개인 추적 목적으로 제공하지 않습니다.

7. 보안

데이터와 API 인증정보는 운영자가 관리하는 로컬 환경에 저장됩니다. API Key는 공개 저장소나 공개 화면에 표시하지 않으며, 가능한 경우 애플리케이션과 API 사용 범위를 제한합니다.

8. 데이터 삭제 및 문의

서비스와 관련된 데이터 처리 또는 삭제에 관한 문의는 아래 연락처로 접수할 수 있습니다. 요청 내용을 확인한 후 적용되는 법률과 YouTube API 정책에 따라 처리합니다.

9. 외부 서비스 정책

서비스의 YouTube API 사용에는 YouTube 및 Google의 정책이 적용됩니다.

  • YouTube 서비스 약관
  • Google 개인정보처리방침
  • YouTube API 서비스 개발자 정책

10. 방침 변경

서비스 기능이나 관련 정책이 변경되는 경우 본 방침을 수정할 수 있습니다. 중요한 변경사항은 시행 전에 이 페이지에 표시합니다.
